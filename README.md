# Elective Recommender

A web application for recommending electives to students.

## Links

Live website: https://elective-recommender-qf8e-ajm3uik76-kamlesh2.vercel.app/

Backend: https://electiverecommender.onrender.com

## Tech Stack

* Angular
* React
* Node.js
* Express
* MongoDB

## Project Structure

* `ang/` - Angular frontend
* `reactapp/` - React frontend
* `backend/` - Express backend


## Running Locally

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd ang
npm install
ng serve
```

The backend uses MongoDB for storing the application data.
